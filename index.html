The complete map — AI agent workflow

Five phases, from mapping the code to closing the flywheel. Rendered as a Mermaid flowchart.

%% ---------- PHASE 1 ----------
subgraph P1["PHASE 1 · RESEARCH — map the thing before you touch it"]
  direction TB
  brief["Brief the agent:
just the map of X
(X = thing being changed)"]
  dontask["Don't ask for solutions"]
  readcode["Docs suck? Don't read them —
read the code"]
  brief --> dontask --> readcode
  readcode --> artifact["Research artifact"]
  artifact --> contains{{"Must contain"}}
  contains --> subj["Subject of the map
e.g. the auth module"]
  contains --> callers["Callers — who actually
calls the fns / classes / APIs"]
  contains --> docs["Docs — exist? accurate?
last updated when?"]
  contains --> rel["Relationships"]
  contains --> notes["Notes — interesting / off"]
  contains --> sa1["Static analysis"]
end

%% ---------- PHASE 2 ----------
subgraph P2["PHASE 2 · GRILL & ALIGN — agree on goal and difficulty"]
  direction TB
  nom["Nomenclature:
everyone agrees on the
name of stuff"]
  hard{"How hard
is the task?"}
  simple["Simple
e.g. button colour
→ no need to grill"]
  grill["Hard → Grill me"]
  onesentence["Define the goal
in ONE sentence"]
  align["Alignment:
you + agent agree
on direction"]
  nom --> hard
  hard -->|simple| simple
  hard -->|hard| grill
  simple --> align
  grill --> onesentence --> align
end

%% ---------- PHASE 3 ----------
subgraph P3["PHASE 3 · PLAN — turn the map into a safe plan"]
  direction TB
  risk["RISK / blast radius
more touches = more risk"]
  br["Blast radius"]
  fr["Failure radius"]
  untested["Untested code"]
  ssot["Conflicting SSOTs"]
  limit["Limit the damage"]
  risk --> br & fr & untested & ssot --> limit

  guard["GUARDRAILS —
hard rules of what NOT to do"]
  g1["Do not change
downstream callers"]
  g2["Do not introduce
new APIs / classes"]
  g3["Do not make new files"]
  g4["Do not keep growing
the single god file"]
  gstop(["If a check fails — STOP"])
  guard --> g1 & g2 & g3 & g4 --> gstop

  checks["DETERMINISTIC hard checks / gates"]
  c1["Tests"]
  c2["Linters"]
  c3["AST / grep"]
  c4["Static analysis"]
  checks --> c1 & c2 & c3 & c4

  tickets["TICKETS — can a junior execute
from ONLY this document?"]
  t1["Ticket 1"]
  t2["Ticket 2"]
  t3["Ticket 3"]
  tickets --> t1 --> t2 --> t3
end

%% ---------- PHASE 4 ----------
subgraph P4["PHASE 4 · EXECUTE — one ticket at a time, gated"]
  direction TB
  take["Take ticket 1"]
  try["Let the agent try"]
  run["Run checks"]
  failed{"Failed?"}
  pass["Pass → next ticket"]
  retry["Retry — but STOP if it breaks
repeatedly or hits a
complete non-negotiable"]
  take --> try --> run --> failed
  failed -->|no| pass
  failed -->|yes| retry
end

%% ---------- PHASE 5 ----------
subgraph P5["PHASE 5 · JOURNAL / LEDGER OF WORK"]
  direction TB
  fail2["Failure — logged, not hidden"]
  attempts["Multiple attempts recorded"]
  fly["Flywheel:
each pass sharpens the next"]
  fail2 --> attempts --> fly
end

%% ---------- CROSS-PHASE FLOW ----------
sa1 --> nom
align --> risk
limit --> tickets
gstop -. stop .-> retry
t3 --> take
retry --> fail2
fly -. "tickets v2 = tickets + journal" .-> tickets
